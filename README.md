# FAQ-бот на 5 вопросов

Простой консольный FAQ-бот для задания трека **«LLM-приложения»**. Бот отвечает на 5 заранее известных вопросов по репетиции хакатона и ищет наиболее подходящий ответ по совпадению ключевых слов.

## Что умеет бот

Бот работает с пятью темами:

- время репетиции;
- команда;
- трек;
- сдача проекта;
- призы.

Если в вопросе пользователя есть слова, совпадающие с ключевыми словами одной из тем, бот выводит соответствующий ответ. Если подходящего совпадения нет, бот отвечает: `Не знаю`.

## Структура проекта

```text
.
├── bot.py      # основной скрипт бота
├── faq.txt     # 5 пар вопрос–ответ
└── README.md   # описание и инструкция по запуску
```

Файл `faq.txt` использует формат:

```text
Тема | Вопрос | Ответ
```

## Требования

- Python 3.8 или выше;
- сторонние библиотеки не требуются.

Используются только стандартные модули Python.

## Как запустить

1. Клонировать репозиторий и перейти в папку проекта:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ>
```

2. Запустить бота:

```bash
python bot.py
```

Если команда `python` не работает, можно попробовать:

```bash
python3 bot.py
```

## Пример работы

```text
=== FAQ-бот готов к работе! ===
Задайте вопрос про репетицию (время, команда, трек, сдача, призы).
Для выхода введите 'выход' или 'exit'.

Вы: Когда проходит репетиция?
Бот: Репетиция проходит по вторникам и четвергам с 18:00 до 20:00.

Вы: Какой дедлайн сдачи?
Бот: Проект необходимо сдать до 23:50 воскресенья в виде ссылки на Git-репозиторий.

Вы: Какая сегодня погода?
Бот: Не знаю
```


## Как работает поиск

1. Бот загружает данные из `faq.txt`.
2. Текст вопроса пользователя переводится в нижний регистр.
3. Из текста удаляется пунктуация, после чего он разбивается на слова.
4. Для каждой записи FAQ считается количество совпадающих слов.
5. Бот выбирает ответ с наибольшим количеством совпадений.
6. Если совпадений нет, возвращается `Не знаю`.

Для этого задания RAG, LLM, embeddings и внешние API не используются — достаточно поиска по ключевым словам.
