# FAQ-бот для репетиции

Консольный чат-бот, отвечающий на 5 основных вопросов о репетиции на основе ключевых слов.

## Структура репозитория
* bot.py — основной скрипт бота.
* faq.txt — база данных вопросов и ответов (формат: `Тема | Вопрос | Ответ`).
* README.md — инструкция и описание работы.

## Требования
* Python 3.8 или выше.
* Сторонние библиотеки не требуются (используются только стандартные модули).
